# AI PDF Chatbot

## About
An AI-powered chatbot that answers questions
using information from uploaded PDF documents.

## Features
- Upload PDF documents
- Extract text from PDFs
- Ask questions about documents
- Generate AI-powered answers

## Technologies
- Python
- Streamlit
- PyMuPDF
- Sentece Transformers
- Ollama

## Installation 

pip install -r requirements.txt

## Run the Application

streamlit run app.py
